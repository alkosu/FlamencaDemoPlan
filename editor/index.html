Проверка ищет оторванные куски, висячие концы и лестницы, до которых нельзя дойти от точек старта.
Как опубликовать для всех
  1. Нажмите
  2. Откройте data/edits.json на GitHub, выделите весь текст (Ctrl/⌘+A), вставьте (Ctrl/⌘+V), нажмите Commit changes.
  3. Через 1–2 минуты навигатор начнёт использовать новые данные. Сборка не нужна.

Можно и файлом: Скачать edits.json → загрузка в папку data. Важно: файл должен называться ровно edits.json. Браузер при повторном скачивании называет его «edits (2).json» — такой файл навигатор не читает; переименуйте перед загрузкой.

Проверить до публикации

Предпросмотр в навигаторе открывает сайт с текущими правками только на этом устройстве. Остальные видят опубликованную версию.

Продолжить в другой раз

Черновик автоматически сохраняется в этом браузере. На другом устройстве нажмите Загрузить файл… и выберите скачанный edits.json.
