# Конвейер сводного плана

Скрипты, которыми четыре листа мастер-плана (`source/sheets/`) были совмещены и разобраны в модель `data/master/*.json`. Навигатору они не нужны: страница собирается из готовой модели командой `python tools/build.py`. Эти скрипты пригодятся, если придёт новый лист или исправленная версия плана.

Зависимости: `numpy`, `opencv-python-headless`, `scikit-image`, `cairosvg` (только для превью).
Скрипты писались как рабочие и ждут нормализованные листы `f1.png … f4.png` в текущей папке (f1 — Фаза 1, повёрнутая в альбомную ориентацию; f2 — Фаза 2; f3 — Фаза 3; f4 — корпуса 14–17).

| Шаг | Скрипт | Что делает |
|---|---|---|
| 1 | `reg.py`, `compose.py` | совмещение листов: SIFT там, где хватает общих деталей, и ручные опорные точки (бассейны, лагуна, отметки высот) → `global.json` с матрицами в общую систему координат |
| 2 | `composite.py` | сводная подложка `master.jpg`: каждый участок берётся со «своего» листа |
| 3 | `km.py` | кластеризация цветов каждого листа (корпуса, террасы, галереи, дорожки…) |
| 4 | `stacks_all.py` + `data/master/blocks.json` | контуры стояков квартир по ручной разметке блоков (коды квартир и границы стояков сверены по увеличенным фрагментам) |
| 5 | `vec_master.py` | векторные слои территории по сводной подложке |
| 6 | `poi.py`, `assemble.py` | объекты легенды и лестницы, сборка `model.json` (стояки, квартиры, лестницы) |
| 7 | `graph.py`, `graph2.py` | сеть пешеходных дорожек: скелет проходимых зон → граф, срезка «шпор», привязка лестниц |
| 8 | `export.py` | отдельный SVG и CSV (в репозитории их делает `tools/build.py`) |

Вспомогательные: `grid.py`, `rcrop.py`, `axgrid.py` — фрагменты листов с координатной сеткой для ручной сверки.
