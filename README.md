# FlamencaDemoPlan

Демо-навигатор жилого комплекса.

Интерактивный план жилого комплекса (корпуса 14–17): поиск квартиры по номеру или коду, пеший маршрут по территории до ближайшей лестницы, переключение этажей и слоёв плана.

![Векторный план с маршрутом до квартиры B3a-403](docs/screenshot.png)

## Что умеет

- **Поиск квартиры**: по номеру (`449`) или коду (`A3a-449`), с подсказками и навигацией с клавиатуры.
- **Маршрут** от входа с Calle Jalón, от парковок, от бассейна или от любой точки, отмеченной кликом на плане. Показываются расстояние, время и пошаговое описание: вход, лестница, этаж.
- **Векторный план со слоями**. Корпуса, галереи, дорожки, проезды, парковка с номерами мест, озеленение, бассейн и подписи включаются по отдельности. Есть готовые наборы и исходная картинка с регулируемой прозрачностью для сверки.
- **Блоки квартир**: по одному на стояк, с подписями выбранного этажа или сразу всех четырёх. Блоки раскрашены по ближайшей лестнице. Лишнее скрывается режимами «Все / Корпус / Квартира».
- **Реестр квартир**: этаж, стояк, лестница, лифт, как пройти, расстояние от входа. Есть фильтры и копирование в CSV.
- **Прямые ссылки на квартиру**: `index.html#A3a-449`.
- Работает без сервера и без сборщиков: одна страница, чистый JS, никаких зависимостей в браузере.

## Быстрый старт

Откройте `index.html` в браузере. Страница работает и с диска (`file://`), потому что данные подключаются как обычный скрипт, без `fetch`.

Локальный сервер, если удобнее:

```bash
python -m http.server 8000
# http://localhost:8000
```

### Публикация на GitHub Pages

1. Запушьте репозиторий на GitHub.
2. **Settings → Pages → Build and deployment**: Source — *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту сайт появится по адресу `https://<user>.github.io/FlamencaDemoPlan/`.

Файл `.nojekyll` уже лежит в корне, так что Jekyll не будет обрабатывать файлы.

## Структура

```
index.html              страница (разметка)
assets/app.js           логика: отрисовка, слои, маршруты, поиск, таблица
assets/style.css        стили интерфейса (светлая и тёмная тема)
data/complex.json       ← РУЧНАЯ РАЗМЕТКА: стояки, лестницы, сеть дорожек, точки старта, подписи
data/plan-data.js       сгенерировано: конфиг + векторные слои + контуры квартир
source/plan.jpg         исходный растровый план
export/plan_layers.svg  вектор отдельным файлом со слоями (Inkscape, Figma, Illustrator)
export/apartments.csv   реестр квартир (UTF-8, разделитель «;», открывается в Excel)
tools/build.py          конвейер: картинка + разметка → вектор, данные для страницы, SVG, CSV
```

## Как обновить данные

Всё, что размечено вручную, лежит в `data/complex.json`. Координаты задаются в пикселях исходной картинки (1540×1048).

| Ключ | Что это |
|---|---|
| `stacks` | стояки: корпус, коды квартир сверху вниз (3→0 этаж), `cut` — прямоугольник `[x0,y0,x1,y1]`, в пределах которого из маски здания вырезается блок |
| `escaleras` | лестничные ядра: корпус, номер, координаты и узел сети дорожек, к которому ведёт маршрут |
| `network` | граф пешеходных дорожек: `nodes` (точки), `edges` (отрезки), `stepNames` (подписи шагов маршрута) |
| `starts` | точки старта в списке «Откуда»; первая используется для столбца «От входа» |
| `access` | шаблон описания доступа для каждого корпуса (`{n}` заменяется номером лестницы) |
| `parking`, `badges`, `labels`, `streetLabels` | номера мест, значки корпусов, подписи |
| `site`, `neighbourZone` | контур участка и область соседнего участка (рисуется приглушённо) |
| `image.metersPerPx` | масштаб для расчёта расстояний |

После правок пересоберите данные:

```bash
pip install -r tools/requirements.txt
python tools/build.py
```

Скрипт перезапишет `data/plan-data.js`, `export/plan_layers.svg` и `export/apartments.csv`.

Чтобы посмотреть граф дорожек поверх плана, включите в панели слоёв набор **«Сверка с исходником»**.

### Как устроена векторизация

`tools/build.py` относит каждый пиксель картинки (после медианного размытия) к ближайшему цвету фиксированной палитры. Классы: корпус, терраса, галерея, дорожка, проезд, парковка, газон, деревья, бассейн и так далее. Для каждого класса строятся контуры (OpenCV) и упрощаются. Корпуса и квартиры дополнительно приводятся к прямым углам: маска огрубляется до сетки 3×3 px. Палитра задана константой `PALETTE`. Если меняется оформление исходного листа, палитру нужно подобрать заново.

Если у застройщика есть DWG/DXF или векторный PDF, лучше брать слои оттуда: контуры станут точными, и автоматический разбор по цветам не понадобится.

## Допущения и ограничения

- **Этаж** берётся из цифры в коде квартиры: `A3a-449` — 3-й этаж, 0 — planta baja.
- **Ближайшая лестница** определяется по расстоянию от центра стояка до лестничного ядра.
- **Лифты** на исходном листе не обозначены. Принято, что лифт стоит в ядре каждой лестницы, это нужно сверить с поэтажными планами.
- **Escalera 2 корпуса 15** на исходном плане не подписана и определена по штриховке.
- **Расстояния** приблизительные: масштаб оценён по ширине парковочного места (~0,1 м/px).
- **Маршрут** строится до входа на лестницу. Путь по галерее до двери и внутри подъезда описывается текстом.
