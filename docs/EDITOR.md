# Редактор данных навигатора

Адрес: **https://alkosu.github.io/FlamencaDemoPlan/editor/**. Из навигатора на него нет ссылок, жильцы его не видят.

Редактор правит сеть дорожек, положение лестниц, точки «Откуда», лифты и щиты воды. Всё сохраняется в один файл `edits.json`. Навигатор подхватывает `data/edits.json` сам, сборка не нужна.

## Инструменты

| Кнопка | Клавиша | Что делает |
|---|---|---|
| Выбрать | V | двигать узлы и значки; клик по значку — его свойства справа |
| Рисовать | D | клики по точкам дорожки; концы прилипают к узлам и отрезкам; Enter, Esc или повторный клик — закончить |
| Удалить | X | клик по узлу — узел со всеми отрезками, по отрезку — только отрезок, по значку — значок |
| Закрыть | C | отрезок становится непроходимым (красный пунктир); повторный клик открывает |
| Маршрут | R | два клика — маршрут и длина, как в навигаторе |
| Вход / Откуда | S | вход или точка старта: названия на четырёх языках, тип (вход или место), информация, ссылка |
| Информация | I | точка «i»: заголовок, текст, ссылка |
| Гараж | G | въезд в гараж: название, текст, ссылка |
| Лифт | L | новый лифт; лестница подставляется ближайшая |
| Щит воды | W | щит воды; квартиры, информация, ссылка, фото |
| Электрощит | E | электрический щит; квартиры, информация, ссылка |
| Привязка | P | контрольная точка для привязки плана к местности |

У входов, точек «i», гаражей и щитов есть поля **«Информация»** и **«Ссылка»**. В навигаторе по клику на значок открывается окно с этим текстом и кнопкой ссылки. Адреса `https://…` внутри текста становятся ссылками, а `**так**` — жирным. Щиты (вода и электричество) видны только в режиме Pro.

Ещё: Ctrl+Z — отменить. Колесо мыши или два пальца — масштаб. Перетаскивание пустого места — сдвиг плана.

Вкладка **Проверка** показывает, связная ли сеть, сколько висячих концов и достижимы ли все лестницы от каждой точки старта.

## Вкладка «Информация» (простой режим)

Вкладка **Инфо-страница** в редакторе — это текст вкладки «Информация» в простом режиме навигатора, на четырёх языках. Если язык не заполнен, показывается испанский, затем английский. Если текста нет вовсе, вкладка в навигаторе не появляется.

Разметка: `# Заголовок`, `## Подзаголовок`, `- пункт списка`, `**жирный**`, `[текст](https://ссылка)`, пустая строка — новый абзац.

## Привязка к местности («Где я»)

1. Инструмент **Привязка** (P): кликните по узнаваемому месту плана — углу корпуса, углу бассейна.
2. В Google Maps (вид «Спутник») правой кнопкой мыши на то же место. Первая строка меню — «широта, долгота», клик её копирует; на телефоне — долгое нажатие. Вставьте в поле справа.
3. Повторите для 5–8 точек по всему комплексу.

Вкладка **Привязка** показывает ошибку каждой точки и среднюю. Хороший результат — 1–3 м. Точка с ошибкой заметно больше остальных взята не с того угла. С 2 точками строится подобие (сдвиг, поворот, масштаб), с 3 и больше — аффинное преобразование. При 3 точках ошибка всегда 0, поэтому для честной оценки нужно 4 и больше.

После публикации в навигаторе появляется кнопка **«Где я»** (◎): синяя точка с кругом точности, а в списке «Откуда» — пункт «Моё местоположение». Геолокация работает только по HTTPS, то есть на GitHub Pages, и только после разрешения в браузере.

## Сохранение и публикация

1. **Черновик** сохраняется в браузере автоматически и предлагается при следующем открытии.
2. **Предпросмотр в навигаторе** открывает сайт с текущими правками только на этом устройстве (`?preview=1`).
3. **Скачать edits.json**, затем на GitHub: `data` → **Add file → Upload files** → перетащить файл → **Commit changes**. Прямая ссылка: https://github.com/alkosu/FlamencaDemoPlan/upload/main/data
4. Через 1–2 минуты навигатор у всех работает с новыми данными.

Чтобы продолжить на другом устройстве: **Загрузить файл…** → выбрать скачанный `edits.json`. Если файл уже опубликован, редактор сам откроет `data/edits.json`.

## Формат файла

```json
{
  "format": "flamenca-edits", "version": 1, "updated": "2026-10-14T16:00:00Z",
  "graph": { "nodes": [[x, y], …], "edges": [[a, b], …], "closed": [[a, b], …] },
  "stairs": { "15-E1": [x, y], … },
  "starts": [{ "id": "jalon", "x": 139, "y": 735, "name": { "es": "…", "en": "…", "fr": "…", "ru": "…" } }],
  "lifts":  [{ "id": "L-15-E1", "stair_id": "15-E1", "floors": "0-3", "serves": "", "note": "", "x": 0, "y": 0 }],
  "water":  [{ "id": "W-15-3-1", "block": "15", "floor": 3, "place": "galería", "kind": "contadores", "serves": "449 443", "info": "", "link": "", "x": 0, "y": 0 }],
  "points": [{ "type": "elec | info | garage", "id": "E-15-0-1", "title": "", "info": "текст окна", "link": "https://…", "x": 0, "y": 0 }],
  "info":   { "es": { "title": "Información", "text": "# …" }, "en": {…}, "fr": {…}, "ru": {…} },
  "georef": { "points": [{ "x": 200, "y": 300, "lat": 37.99, "lon": -0.68, "note": "угол корпуса 16" }] }
}
```

Координаты — пиксели сводного плана `source/master.jpg` (0,1 м на пиксель). `serves` у лифта пустой — лифт обслуживает все квартиры своей лестницы.

## Порядок источников

`data/edits.json` (если есть) → `data/plan-data.js` (собирается `tools/build.py` из QGIS-файла или автосети). Редактор и QGIS можно не сочетать: если работаете в редакторе, QGIS не нужен.
